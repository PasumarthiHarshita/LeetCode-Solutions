# 12. Integer to Roman

**Difficulty:** Medium

## Problem

Given an integer, convert it to a Roman numeral.

Roman numerals use the following symbols:

| Symbol | Value |
|--------|-------|
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1000 |

The following subtractive forms are used:

- `IV` = 4
- `IX` = 9
- `XL` = 40
- `XC` = 90
- `CD` = 400
- `CM` = 900

## Example 1

**Input:** `num = 3749`

**Output:** `"MMMDCCXLIX"`
